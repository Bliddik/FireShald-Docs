# Механики сервера

## <span style={{ color: '#FFFFF' }}>Экономика</span>

### 💰Денежная система
Валюта сервера — монеты ()

**Возможности:**
- Проверка баланса
- Переводы между игроками
- Покупка в магазине
- Продажа купцам

### 🏪Магазин
Доступен только на спавне.

**Категории:**
- Боевые артефакты
- Материалы призыва
- Магические осколки
- Ритуальные компоненты
- Ремесленные материалы
- Редкости и коллекции

### 🏪Система покупателей

**Глобальный купец:**
- Динамические цены на основе спроса/предложения
- При продаже цена предмета падает, другие растут

**Локальный купец:**
- 5 уровней репутации
- Получение опыта: 1 за каждый проданный предмет

| Уровень | Название | Множитель |
|---------|----------|-----------|
| 1 | Новичок | 1.0x |
| 2 | Ученик | 1.2x |
| 3 | Профессионал | 1.4x |
| 4 | Эксперт | 1.7x |
| 5 | Мастер | 2.0x |


## <span style={{ color: '#FFFFF' }}>Телепортация</span>

### 📍TPA (запрос)
Отправка запроса на телепортацию к другому игроку.

Команды:
- `/tpa [игрок]` — отправить запрос
- `/tpc` — принять запрос
- `/tpd` — отклонить запрос

**Особенности:**
- Перезарядка между запросами
- Запрос истекает через время
- Нельзя отправить новый, пока есть активный

### 🎲RTP (случайная)
Телепортация в случайную точку мира.

**Особенности:**
- Перезарядка несколько минут
- Поиск безопасной локации
- Подготовка с обратным отсчётом

### 🏠Система домов
Установка личных точек телепортации.

**Ограничения:**
- Лимит домов на игрока
- Название: буквы и цифры, 1-9 символов
- Уникальные названия

Команды:
- `/sethome [название]` — установить дом
- `/home` — открыть меню домов


## <span style={{ color: '#FFFFF' }}>Дополнительные системы</span>

### ✨Происхождения (Origins)
Выбор происхождения при старте:

- **Воин** — бонусы к ближнему бою
- **Маг** — бонусы к магии
- **Танк** — бонусы к защите и здоровью
- **Фермер** — бонусы к фермерству
- **Шахтер** — бонусы к горному делу
- **Вор** — бонусы к воровству

Некоторая экипировка требует определённое происхождение.

### 📚Система обучения (Tutorial)
Проводится в отдельном мире-гиде.

**Этапы:**
1. Боевые навыки — убить тень
2. Горное дело — добыть уголь
3. Копание — выкопать землю
4. Вспахивание — вспахать грядки
5. Фермерство — посадить семена
6. Рубка деревьев — срубить деревья
7. Магия — использовать посох

Можно пропустить без получения наград.

### 💬Чат

**Типы сообщений:**
- Локальный — игроки в радиусе ~100 блоков
- Глобальный — префикс `!`, видят все

**Модерация:**
- Лимит длины сообщения
- Защита от капса и спама
- Перезарядка между сообщениями

### 😴AFK система
- Предупреждение при бездействии
- Кик через 2 минуты AFK
- Обнаружение подозрительной активности (боты)
